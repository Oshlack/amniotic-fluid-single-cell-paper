To preprocess this dataset, the following steps will be performed:

  • filtering empty droplets using emptyDrops()
  • filtering cells with high mitochondrial proportion using adaptive thresholds
  • filtering out cells with low library size and few detected genes
  • feature selection
  • conversion from a SingleCellExperiment object to a Seurat object for downstream analysis

5 Calling cells from empty droplets

5.1 Using DropletUtils

Droplet-based single-cell datasets contain numerous droplets that lack cells (known as empty droplets). These are distinguished from droplets containing cells and removed from the dataset based on their expression profile. This is done separately for each 10x run (although Dataset #3 only contains a single run).

This process is complicated as empty droplets contain ambient (extracellular) RNA that is captured and sequenced, so therefore the distribution of total UMI counts vs. barcode rank is examined. A sharp transition between barcodes of large total counts to barcodes of small total counts is indicative of a transition from droplets containing cells to empty droplets.

bcrank <- barcodeRanks(counts(sce))

This histogram shows the p-value distribution for emptyDrops(). Peaks near zero suggest that lower should be decreased as cells with library sizes below this value are being flagged as empty droplets.

Cells are called at a false discovery rate of 0.1%, meaning that no more than 0.1% of the called barcodes should be empty droplets on average.
